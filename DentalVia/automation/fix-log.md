# Article-quality fix log — DentalVia

Automated runs of the article-quality fixer: (A) resolve publish-blocking flags so every
draft is publish-ready, and (B) humanise low Gemini-score articles. Work happens on each
article's own `dv-content/<folder>` branch (updating its open PR). Facts, numbers, medical
claims, prices, dates, compliance lines (medical disclaimer, mediation-transparency line),
byline (Georgi Todorov / Mario Yordanov), and brand name (DentalVia) are never changed —
humanising and flag-resolution are rephrasing only.
