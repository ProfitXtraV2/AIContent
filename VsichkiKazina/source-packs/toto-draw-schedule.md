## Where official results appear
- Per-game results page: `https://info.toto.bg/results/<game>` (e.g. `/results/6x49`). It defaults to
  the latest тираж and has a „ИЗБЕРИ ТИРАЖ“ selector for older draws. It shows the тираж number + date,
  печеливши числа, джакпот, and a prize table (брой печалби / размер / обща сума per category).
- Amounts are shown in **EURO** (Bulgaria has used the euro since 2026).
