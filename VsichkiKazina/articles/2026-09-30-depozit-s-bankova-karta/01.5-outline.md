# 01.5-OUTLINE — vk-0224 · Депозит с банкова карта

H1: Депозит с банкова карта (Visa/Mastercard) в онлайн казино: такси, срокове и сигурност
Hero: ПРОПУСНАТ (AI hero API офлайн, HTTP 402). Вместо hero — SVG инфографика при данните за срокове.

Byline: persona (Георги Тодоров). БЕЗ Протокол на тегленето (няма разписки).

Секции (варирани форми, реални читателски въпроси; anti-tell дисциплина):
1. Интро — картата е най-разпространеният метод, депозитът моментален; тежестта е в тегленето/таксите/KYC; тестер frame („банерът е реклама, общите условия са договорът"). Отваря с факт, не с hook.
2. „Защо картата стои първа в списъка" — приемана навсякъде, дебит/кредит, без отделен профил; лимити варират. → /blog/casino-payments/.
3. „Как минава самият депозит" — карта/срок/CVV, 3-D Secure (Verified by Visa / Mastercard Identity Check), моментално; + под-параграф „ако депозитът бъде отказан" (банка блокира хазартни MCC / 3-D Secure ненастроен).
4. „Тегленето обратно по картата не е моментално" — 1–5 работни дни, зависи от банка/казино; KYC при първото (лична карта/паспорт, адрес, снимка на картата). → SVG инфографика ТУК + caption.
5. „Правилото за същата карта" — връщане до размера на депозита; печалбата отгоре по друг метод; изтекла/закрита карта. Примерен €200/€500 пример.
6. „Кой всъщност таксува: казиното или банката" (основната лента на тестера) — казиното обикновено не таксува; банка: валутно конвертиране (примерен €200×2%=€4), евро карта в еврозоната обикновено без конвертиране (→ /blog/evro-hazart-depoziti/); кредитна карта = cash advance (~3–5% + лихва, [VERIFY]); дебитната по-евтина.
7. „Колко е сигурно да даваш картата си онлайн" — PCI DSS/токенизация (казино); проверката на играча: лиценз НАП, https, 3-D Secure; RG докосване + верб. 18+ ред + /otgovorna-igra/.
8. „Кратка равносметка" — асиметричен verdict: за депозит най-простото, за теглене рядко най-бързото, с кредитна карта най-скъпото; провери тарифата преди да въведеш номера. → /depoziti-i-teglenia/.

Anti-tell watch: без „не A, а B" завършек на абзаци (макс. веднъж); без „Причината е проста:"/„Какво означава това:"; без numbered „Първата… Втората…" в прозата; без rule-of-three негации; без aphoristic bow на всеки абзац; асиметричен финал; 0 em-dash; en-dash само в числови диапазони.
