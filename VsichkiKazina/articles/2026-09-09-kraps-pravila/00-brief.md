## GAME FACTS (public game math — sourced)
- 2 шестстенни зара; стрелец; come-out хвърляне; точка (point).
- Come-out: 7/11 win pass · 2/3/12 lose (craps) · 4/5/6/8/9/10 = point. Point преди 7 = win; 7 first (seven-out) = lose.
- Pass line house edge 1.414% (~1.41%).
- Don't pass 1.364% (of all wagered) / 1.40% per resolved bet; „bar 12" push.
- Come 1.414% / Don't Come 1.364%.
- Odds bet (free odds): 0.00% edge — истински коефициенти 4/10=2:1, 5/9=3:2, 6/8=6:5. Pass+2x odds комбинирано ~0.57%; Don't pass+2x ~0.46%.
- Place: 6/8 1.515% · 5/9 4.0% · 4/10 6.667%.
- Field 5.556% (12 pays 2:1) / 2.778% (12 pays 3:1).
- Prop/center: Any 7 16.667% (worst) · Any Craps 11.111% · hard 4/10 11.111% · hard 6/8 9.091% · Big 6/8 9.091%.
