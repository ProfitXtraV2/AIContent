This bank holds possible NEW pages only. Existing pages are tracked in `topic-backlog.md` as
`page-rewrite` rows. A new page is never written from this bank until its address and main term
are in `BizGrow/keyword-map.md` with status `planned`. Prices stay out of scope, so a price page
is not a candidate. Data source: Ahrefs API `country=bg` (`country=us`/`gb` only for `/en/`
pages if the owner asks; key from `$AHREFS_API_KEY`), web fallback marked `checked = web`; never
fabricate volumes.
